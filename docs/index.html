Arrow, Parquet, and DuckDB for Marketing Analytics

A Practical Guide Using Google Analytics 4 Public Data

Welcome

This site is a companion resource for the Marketing Analytics course at Cal Poly Pomona MSDM Program. It provides a hands-on, code-first introduction to modern tools for working with large-scale marketing data in R — specifically the kind of high-volume event data that real-world analytics platforms like Google Analytics 4 produce.

All examples use the GA4 Obfuscated Sample E-commerce Dataset — a publicly available BigQuery dataset derived from real user behavior on the Google Merchandise Store. This means every technique you learn here applies directly to the GA4 data your future employer is already collecting.

What You Will Learn

The notebooks in this series build on each other in a deliberate sequence:

Step Topic Key Skill
1 Arrow and Parquet Read and write columnar files; query larger-than-RAM data
2 Data Acquisition from BigQuery Download 90 days of GA4 data and save in multiple formats
3 DuckDB Run SQL and dplyr queries on Parquet files without loading into RAM
4 duckplyr Use dplyr syntax powered by DuckDB for production-scale speed

By the end of this series you will be able to take raw GA4 event data from BigQuery and turn it into clean, fast, queryable local datasets that support real marketing analyses — traffic source performance, purchase funnels, content analytics, and e-commerce reporting.

Why These Tools?

Traditional approaches to marketing data analysis load everything into RAM as a flat data frame. This works fine for small datasets but breaks down quickly when you have millions of events, dozens of dimensions, and deeply nested data structures. The tools in this series solve each layer of that problem:

NoteParquet

Stores data in a compressed columnar format that is 10–50× smaller than CSV and reads 5–10× faster. It is the industry standard for analytical data storage and is readable by R, Python, Spark, and Tableau.

NoteArrow

A library for reading, writing, and processing Parquet files in R. It allows you to query files that are larger than your RAM by loading only the columns and rows your query actually needs — a technique called lazy evaluation.

NoteDuckDB

An embedded analytical database that runs inside R with zero server setup. It reads Parquet files directly and executes SQL or dplyr queries at speeds that rival dedicated cloud data warehouses.

Noteduckplyr

Brings DuckDB’s engine to your existing dplyr code with no syntax changes — the same verbs, the same pipes, dramatically faster execution on large data. The ideal upgrade path from dplyr for production-scale marketing analysis.

TipRectangling Hierarchical Data

GA4 stores event data in a nested format — arrays of structs inside structs — that must be flattened before it can be saved as Parquet or analysed with standard tools. This flattening process is called rectangling.
